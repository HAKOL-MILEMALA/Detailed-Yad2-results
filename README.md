# יד2 - סינון סוכנויות, הוספת מפות ושליפת נתונים 🚗

סקריפט Tampermonkey מתקדם לאתר **יד2** המשפר את חווית החיפוש והעיון במודעות רכב.

[![Install Script](https://img.shields.io/badge/Tampermonkey-Install_Script-green?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/HAKOL-MILEMALA/Detailed-Yad2-results/main/Detailed-Yad2-results.user.js)

---

## ✨ תכונות עיקריות

* 🚫 **סינון סוכנויות:** תיבת סימון (Checkbox) מהירה להסתרה או הצגה של רכבי סוכנויות ומגרשים.
* 📊 **שליפת נתונים מורחבת:** הצגת קילומטראז', מיקום מדויק ותיאור הרכב ישירות על כרטיסיית הנתונים, ללא צורך לפתוח כל מודעה בנפרד.
* 🗺️ **קישור לגוגל מפות:** הוספת קישור ניווט ישיר ל-Google Maps לפי המיקום המצוין במודעה.
* ⚡ **ניהול מטמון (Cache):** מנגנון שמירה במטמון למניעת קריאות חוזרות לשרת וחיסכון במשאבים.
* ❤️ **תמיכה בעמוד מועדפים:** הסקריפט עובד בצורה מלאה גם בדף החיפוש הראשי וגם בעמוד המועדפים האישי.

---

## 📥 הוראות התקנה

1. ודא שמותקן בדפדפן שלך תוסף לניהול סקריפטים, כגון [Tampermonkey](https://www.tampermonkey.net/).
2. לחץ על הקישור להורדה ישירה:
   
   👉 **[לחץ כאן להתקנת הסקריפט בלחיצה אחת](https://raw.githubusercontent.com/HAKOL-MILEMALA/Detailed-Yad2-results/main/Detailed-Yad2-results.user.js)**

3. בחלון שנפתח ב-Tampermonkey, לחץ על **Install** (התקן).
